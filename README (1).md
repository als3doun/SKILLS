# جعل منصة الموهوبين قابلة للتثبيت (PWA)

أضف هذه الملفات إلى جذر المستودع نفسه (بجانب index.html):
- `manifest.json`
- `sw.js`
- مجلد `icons/` (ثلاث أيقونات PNG)

ثم افتح `index.html` وألصق الأسطر الموجودة في `head-snippet.html` (سطور في `<head>` وسطر قبل `</body>`).

بعد رفع التعديلات وانتظار تحديث GitHub Pages، افتح الرابط في Chrome/Edge (أندرويد أو كمبيوتر) واختر «تثبيت التطبيق».
على iPhone: Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية».

ملاحظات: يجب أن يكون الرابط https (متوفر في GitHub Pages). الروابط الخارجية (يوتيوب وغيره) تحتاج إنترنت.
